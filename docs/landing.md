# Landing page

The public landing page is maintained separately (Lovable, deployed to
Cloudflare Workers static assets). It links back to this repository.

Until the deployed URL exists, this file is the source of truth for the
relationship: the landing presents the project and collects pilot requests;
this repository carries the code, scenarios, and results. The landing never
states a capability that is not implemented here; in-development features
are labeled as such.
